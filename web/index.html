ヘッドボードLED 設定

ESP32 を USB で接続して、ファームウェアの書き込みと状態の確認を行います。

このブラウザは Web Serial に対応していません。パソコンの Chrome または Edge で開いてください。

1. ファームウェアを書き込む

ボタンを押して ESP32 のシリアルポートを選びます。初めて書き込むときは「消去」を選ぶと保存済みの設定も消えます。

このブラウザでは書き込みできません（Chrome / Edge を使ってください）。 HTTPS または localhost で開いたページからのみ書き込めます。

書き込み画面を閉じてから、下の「2. 接続」で接続してください（同じポートを同時には使えません）。

ファームウェアの更新

更新用のファイル headboard-led-ota.bin を選んで「更新する」を押します。書き込み後に再起動し、起動できなかったときは前のファームウェアに戻ります。

2. 接続

この本体は USB から設定を変更できません（量産版）。Wi-Fi はスマホの Bluetooth で、そのほかの設定は本体の設定ページ（下の URL）で行います。

Wi-Fi

Wi-Fi を変えて繋がらなかったときは、本体の BOOT ボタンを 3 秒以上押して離すと、Bluetooth で設定し直せます。

MQTT（Home Assistant）
Tailscale

認証キーは Tailscale 管理画面の Settings → Keys で作成します。MQTT ブローカーのホスト名に tailnet の名前（例: homeassistant）か tailnet のアドレス（100.64〜100.127）を入れると、Tailscale 経由で接続します。IP アドレス以外のホスト名は、LAN の名前でも Tailscale の接続を待ってから繋ぎます。

デバイス
状態表示 LED（基板上のフルカラー LED）

紫: Wi-Fi 未設定（Bluetooth で設定待ち） ／ 青: Wi-Fi 接続中 ／ 水色: Tailscale 接続中 ／ 黄: MQTT 接続待ち ／ 赤: 認証エラー ／ 緑: 正常（既定では 10 秒後に消灯）

Bluetooth 設定用ラベル
